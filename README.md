# 🤖 AI Portfolio Generator

AI-powered web application that generates a professional portfolio from a Resume PDF.

## ✨ Features
- 📄 Resume PDF Upload
- 🤖 AI Portfolio Generation
- 🛠️ Skills & Projects Display
- 📧 Contact Details
- 🔗 Shareable Portfolio Link

## 🛠️ Tech Stack
React.js • Node.js • Express.js • Google Gemini API • JavaScript
